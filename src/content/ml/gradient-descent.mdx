## Introduction

Gradient Descent is an optimization method used to reduce the value of a function.

## The Mathematics

For a differentiable one-dimensional function, we update our current point using:

$$
x_{n+1} = x_n - \alpha f'(x_n)
$$

Here, $\alpha$ is the learning rate and $f'(x_n)$ is the gradient at the current point.

## Summary

Gradient Descent moves against the local gradient. The learning rate affects how far it moves on each step.
